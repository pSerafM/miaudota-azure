# Prompt utilizado

Crie um frontend web simples para um projeto de adoção de animais chamado **MiAuDota**, utilizando apenas **HTML, CSS e JavaScript**, sem necessidade de frameworks.

O projeto deve possuir pelo menos duas telas:

1. Uma página inicial para listar os pets disponíveis para adoção.
2. Uma página de cadastro de pets.

Utilize JavaScript para realizar as interações da página e faça uma requisição HTTP utilizando `fetch()` para consumir um endpoint `GET` de uma Azure Function que retorna dados mockados dos pets.

Organize o projeto de forma simples, separando:

* arquivos HTML;
* arquivos CSS;
* arquivos JavaScript;
* serviços responsáveis pela comunicação com a API.

Crie uma interface simples, limpa e responsiva, utilizando cards para apresentar os pets.

O código deve ser simples e adequado para um projeto acadêmico, utilizando HTML, CSS e JavaScript puro.

Não utilizar React ou outros frameworks. Priorizar código fácil de entender e modificar.
